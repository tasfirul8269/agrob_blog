## 📋 Overview

**Agrob** is a clean, responsive blog focused on sustainable agriculture — covering topics like modern farming techniques, eco-friendly practices, and insights into building a greener food system. Built with the Next.js App Router for fast, SEO-friendly rendering and a great reading experience on any device.

---

## ✨ Features

- 📝 **Article-first Design** — Distraction-free reading experience for long-form content
- ⚡ **Next.js App Router** — Server-side rendering and static generation for blazing-fast page loads
- 🔍 **SEO Optimised** — Meta tags and structured content for discoverability
- 📱 **Fully Responsive** — Looks great on mobile, tablet, and desktop
- 🎨 **Modern UI** — Clean, minimal design with Tailwind CSS
- 🔤 **Optimised Fonts** — Uses `next/font` for automatic font optimisation with zero layout shift

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm, yarn, pnpm, or bun

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/tasfirul8269/agrob_blog.git

# 2. Navigate into the project directory
cd agrob_blog

# 3. Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the app.

### Build for Production

```bash
npm run build
npm run start
```
